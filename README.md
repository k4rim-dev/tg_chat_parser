# Telegram Chat Parser

Инструмент для преобразования HTML-экспорта Telegram-чата в единый файл TXT, Markdown или JSON. Поддерживает расшифровку голосовых сообщений и кружков.

## Запуск на Windows

1. Скачать или клонировать репозиторий.
2. Установить Python 3.12 с pip и Tcl/Tk либо [uv](https://docs.astral.sh/uv/).
3. Запустить `setup.bat`. Он создаст `.venv` и установит зависимости.
4. Запустить `start.bat`, выбрать папку экспорта и место сохранения.
5. Включить «Распознавать речь», если нужна расшифровка, и нажать «Собрать переписку».

В Telegram Desktop открыть меню нужного чата, выбрать «Экспорт истории чата» и формат **HTML**. Для расшифровки включить голосовые и видеосообщения. В парсере выбрать папку с `messages.html`. Каталоги с вложениями оставить рядом. Если в экспорте несколько страниц, парсер соберёт их по порядку.

## Расшифровка

| Модель | Когда выбрать | Размер на диске |
| --- | --- | ---: |
| `base` | Быстрее, выбрана по умолчанию | ≈148 МБ |
| `small` | Точнее, работает дольше | ≈486 МБ |

Размеры указаны для файлов моделей, отдельно от зависимостей Python. При первом запуске расшифровки окно спросит, скачивать ли выбранную модель. Для загрузки нужен интернет. Скачанные модели остаются в локальном кэше Hugging Face. Текст и аудио обрабатываются локально.

Крестик в строке останавливает расшифровку этой записи. Частичный текст отбрасывается, а «Возобновить» запускает запись с начала. После обработки списка нажать «Сохранить результат». Если оставить запись отменённой, в экспорте останется ссылка на вложение. «Отменить экспорт» закрывает всю очередь без сохранения.

## Через консоль

```powershell
.venv\Scripts\python parser.py "C:\Exports\ChatExport"
.venv\Scripts\python parser.py "C:\Exports\ChatExport" -o "C:\Exports\chat.md" --transcribe --model small --language ru
.venv\Scripts\python parser.py "C:\Exports\ChatExport" --transcribe --offline
.venv\Scripts\python parser.py --help
```

Без аргументов открывается окно. Без `-o` результат сохраняется в `full_chat.txt` внутри экспорта. Расширение выходного файла определяет формат. Для замены существующего файла указать `--overwrite`. Для автоопределения языка указать `--language auto`.

При ручной установке создать окружение командой `py -3.12 -m venv .venv`, затем выполнить `.venv\Scripts\python -m pip install -r requirements-audio.txt`. Без расшифровки достаточно `requirements.txt`. На Linux/macOS использовать `python3` и `.venv/bin/python`. Для окна может понадобиться системный пакет Tk.

Парсер сохраняет отправителей, даты, тексты, ответы, реакции и ссылки на вложения. Служебные события чата пропускаются. На входе поддерживается только HTML-экспорт. Расшифровка может ошибаться на шумных записях.

## Файлы проекта

| Путь | Что внутри |
| --- | --- |
| `parser.py` | Разбор HTML, форматы результата и консольный запуск. |
| `gui.py` | Основное окно на Tkinter. |
| `audio_queue.py` | Очередь записей и отдельный процесс распознавания. |
| `setup.bat` | Установка зависимостей на Windows. |
| `start.bat` | Запуск окна. |
| `requirements.txt` | Beautiful Soup для разбора HTML. |
| `requirements-audio.txt` | Базовые зависимости, faster-whisper и PyAV. |
| `README.md` | Описание проекта и инструкции. |
| `tests/test_parser.py` | Тесты на вымышленных сообщениях. |
| `.github/workflows/tests.yml` | Запуск тестов в GitHub Actions. |
| `.gitignore` | Исключения для экспортов, результатов и локального окружения. |

Локально могут появиться `.venv/` с библиотеками, `__pycache__/` с кэшем Python и скрытая `.git/` с историей репозитория.

Запуск тестов: `.venv\Scripts\python -m unittest discover -s tests -v`.
